## 测试说明

### 难度级别定义

| 级别 | 描述 | 特点 |
|------|------|------|
| 初级 | 单表查询，简单过滤 | WHERE, ORDER BY, 基础聚合 |
| 中级 | 多表关联，复杂聚合 | JOIN, GROUP BY, HAVING |
| 高级 | 子查询，窗口函数，复杂分析 | 子查询, CTE, 窗口函数, 多层级关联 |

### 测试建议

1. **渐进式测试**: 从初级到高级逐步测试
2. **边界情况**: 测试空结果、大数据量、特殊字符等
3. **性能验证**: 关注复杂查询的执行时间
4. **SQL质量**: 检查生成的SQL是否正确、高效
5. **错误处理**: 测试模糊或错误提示的处理能力

### 预期SQL示例

**SP-009** 预期SQL:
```sql
SELECT c.name, SUM(o.total_amount) AS total_spent
FROM customers c
JOIN orders o ON c.id = o.customer_id
GROUP BY c.id, c.name
ORDER BY total_spent DESC;
```

**MP-017** 预期SQL:
```sql
SELECT s.student_id, s.name, AVG(g.score) AS avg_score
FROM students s
JOIN grades g ON s.id = g.student_id
GROUP BY s.id, s.student_id, s.name
ORDER BY avg_score DESC
LIMIT 10;
```

**LP-021** 预期SQL:
```sql
SELECT p.patient_id, p.name, SUM(ch.total_amount) AS total_charges
FROM patients p
JOIN admissions a ON p.id = a.patient_id
JOIN charges ch ON a.id = ch.admission_id
GROUP BY p.id, p.patient_id, p.name
HAVING SUM(ch.total_amount) > 50000
ORDER BY total_charges DESC;
```
